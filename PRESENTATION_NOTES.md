# DriveNow - Five-minute presentation outline (English)

**Group SE-2501:** Amangeldi Sherkhan, Bekzat Abilkhaev. **Target:** approximately 4:45. Every team member should speak or demonstrate.

## 0:00-0:45 - Introduction

Introduce each team member and group. "DriveNow is our responsive six-page car-rental demonstration. We designed it for people who want to compare rental vehicles and submit a simple booking request. It is a front-end student demo, not a real car-rental agency."

## 0:45-3:55 - Live demonstration

1. **0:45-1:15 Home** - explain blue/white visual theme and the three-step rental planner.
2. **1:15-1:50 Cars** - search for BMW and filter Luxury; demonstrate ratings and selecting a car.
3. **1:50-2:40 Account** - open Login/Sign Up; submit an empty form to show inline errors, then sign in with a previously prepared demo account. Show Profile details.
4. **2:40-3:15 Booking** - submit a demo request, demonstrate phone/date validation, then show it in Profile.
5. **3:15-3:40 API** - in Booking, search `Astana, Kazakhstan`; point to the dynamic location text and map. Mention loading/error handling.
6. **3:40-3:55 Responsive and modes** - switch light/dark; emulate a mobile viewport and open the sidebar.

## 3:55-4:45 - Conclusion

"Our project uses six linked pages, responsive Bootstrap components, JavaScript validation, localStorage authentication simulation and a map API. Everything is organized in HTML, CSS, JavaScript, images and vendor folders. In the future we could add a secure backend and live inventory. Thank you."
