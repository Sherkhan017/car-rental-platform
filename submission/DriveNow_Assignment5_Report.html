1. Objective

The objective was to continue the existing DriveNow website and practise advanced JavaScript and DOM manipulation. We added a car finder, personal demo ratings, a three-step rental planner, keyboard navigation, sound effects, and small animations. We kept the four existing pages and Assignment 4 features.

2. DOM Manipulation and Styling

The Cars page has category buttons and a dynamic car list. JavaScript creates cards and five star buttons for each car. A visitor can select a car and give a personal demo rating. The interface updates the available-car count, selected car, star color, accessibility attributes, and messages.

Steps:

  1. JavaScript finds the filter buttons and list with DOM selection methods.
  2. It filters the car array and creates card elements with text and images.
  3. It adds five rating buttons to every card and sets their initial state.
  4. A click updates the selected stars, aria-pressed, and rating text.

Files: cars.html, js/assignment5.js, css/assignment5.css. The cars and prices are Toyota Camry (30,000 KZT/day), Audi A6 (50,000 KZT/day), BMW 5 Series (40,000 KZT/day), and Mercedes E-Class (60,000 KZT/day), based on the existing project catalogue and booking/pricing information.

These are personal demo ratings, not customer reviews. Text updates use textContent; dynamic car content is created as DOM elements.

3. Event Handling

Buttons use addEventListener("click", ...). The Car Finder uses one click listener on the list for star and car-selection actions. The menu listens for keydown. Arrow keys move focus between links in the focused main or sidebar menu. The handler does not capture arrow keys from text fields.

Steps: focus a menu link; press an arrow key; the script finds the next link in the same menu, prevents the page's default arrow action, and calls focus() on that link. Mouse navigation remains unchanged.

Files: `js/assignment5.js` and the existing navigation in all four HTML pages.

4. Objects and Methods

The car catalogue in `js/assignment5.js` is an array of objects. Each car stores its id, name, category, price, image, description, and current personal demo rating. The `getPriceText()` object method formats a daily price, and the interface calls that method for the car card and planner.

Steps: define one object for each real car; call `getPriceText()` when presenting its price; use the object’s rating property when a visitor selects a star.

5. Arrays, Loops, and Higher-Order Functions

The car objects are stored in an array. A traditional `for` loop creates the five star buttons. `filter()` selects cars by category, `forEach()` renders cards and updates controls, and `map()` creates the rental planner’s car options.

Steps: store the cars; filter them using the selected category; loop through the result to create cards; map car data into select options. The filtering uses a real `switch` statement for All, Comfort, Business, Premium, and Luxury.

File: `js/assignment5.js`.

6. Sound Effects

A short, quiet sound is generated with the Web Audio API after a rating or demo-plan confirmation. It does not autoplay. A new signal stops the previous signal. The Sound button mutes and unmutes playback. If the browser does not support Web Audio, the control reports that sound is unavailable.

Steps: click a star or confirm the demo plan; the browser creates a short tone; use Sound: Off to mute future tones.

Files: `js/assignment5.js`, `cars.html`, `index.html`.

7. Animations

Car cards fade into the page after a category is selected. Rating stars respond when pressed. Planner steps fade or slide into view. CSS contains the transitions and animation rules. A reduced-motion media query limits motion when requested by the user’s device.

Steps: a real user action changes a class; CSS applies a short opacity, color, or position change; reduced-motion settings shorten the effects.

Files: `css/assignment5.css` and `js/assignment5.js`.
