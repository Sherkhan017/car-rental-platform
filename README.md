# DriveNow - Car Rental Platform

DriveNow is a simple car rental website created for the Front-End Development Assignment.

The website helps users view available cars, learn about the company, and send a booking request.

## Pages

The project has 4 main pages:

* `index.html` - Home page
* `cars.html` - Available cars
* `booking.html` - Car booking form
* `about.html` - About the company and team

## Technologies

* HTML5
* CSS3

## Main Features

* Navigation bar on all pages
* Car cards with images and prices
* Booking form
* Car price table
* Team information
* Buttons and hover effects
* Responsive layout
* Footer on every page
