# DriveNow - Car Rental Platform

DriveNow is a simple car rental website created for the Front-End Development Assignment.

The website helps users view available cars, learn about the company, and send a booking request.

## Pages

The project has 4 main pages:

* `index.html` - Home page
* `cars.html` - Available cars
* `booking.html` - Car booking form
* `about.html` - About the company and team

## Technologies

* HTML5
* CSS3

## Main Features

* Navigation bar on all pages
* Car cards with images and prices
* Booking form
* Car price table
* Team information
* Buttons and hover effects
* Responsive layout
* Footer on every page

## Assignment #4: Introduction to JavaScript

We continued the same DriveNow project from Assignments 1-3 and added:

1. **Form validation** (`booking.html`): required fields, email format, password length, password confirmation, dates, and error messages.
2. **FAQ accordion** (`about.html`): click to open/close questions with smooth transitions.
3. **Popup contact form** (`about.html`): open with Contact Us, close with X or outside click.
4. **Background color change** (`index.html`): change page/background-demo colors with a button.
5. **Current date and time** (all HTML pages): uses JavaScript `Date` and updates every second.

- JavaScript: `js/script.js`
- Additional CSS: `css/assignment4.css`
- Original Bootstrap components, layout, and images remain unchanged.
